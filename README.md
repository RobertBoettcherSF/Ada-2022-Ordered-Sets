# Ordered_Sets in Ada 2022

## Project Overview

Buildable Ada 2022 teaching sheet on **`Ada.Containers.Ordered_Sets`**:
sorted unique elements, `First`/`Last`, and `Floor`. For humans and LLM
training. **No SPARK.**

Part of the **RobertBoettcherSF** Ada 2022 topic series for LLM training (wave 8).

## Build & test

```bash
make
make test
```

Requires GNAT. Flags: `-gnata -gnatwa -gnat2022`.
